# GP1157 実機確認済みコマンドメモ

この文書は、`FutabaGP1157 v0.1.0` で実際に使用している範囲だけをまとめた開発メモです。
完全なコマンドリファレンスではありません。

## 通信

- RS-232C
- 38400 bps
- 8 data bits
- no parity
- 1 stop bit

マイコンのTTL UARTとは直接接続せず、MAX3232等のレベル変換を使用します。

## 初期化

```text
1B 40
```

`ESC @`

## 画面クリア

```text
0C
```

## カーソル位置

```text
1F 24 xL xH yL yH
```

- X: 1dot単位
- Y: 8dot単位

ライブラリAPIでは `setCursor(xDot, yDot)` のYをdot値で受け取り、内部で8で割ります。

## 8×16フォント

```text
1F 28 67 01 02
```

## 漢字モード

ON:

```text
1F 28 67 02 01
```

OFF:

```text
1F 28 67 02 00
```

## 文字拡大

```text
1F 28 67 40 x y
```

現在のライブラリではx/yを1～4に制限しています。
16×16漢字へ2×2を指定すると32×32表示として使用できます。

## ボールド

```text
1F 28 67 41 b
```

- `00`: OFF
- `01`: ON

## 輝度

```text
1F 58 n
```

現在使用している値:

| n | 輝度 |
|---|---:|
| `10h` | 0% |
| `01h` | 25% |
| `02h` | 50% |
| `03h` | 75% |
| `04h` | 100% |

## 上書きモード

```text
1F 01
```

## 横スクロールモード

```text
1F 03
```

## スクロール速度

```text
1F 73 n
```

ライブラリでは `0..31` に制限しています。

## 日本語

GP1157へはShift-JISで送信します。
Arduinoスケッチ側ではUTF-8文字列を書き、ライブラリがShift-JISへ変換します。

## 部分更新

GP1157はカーソルを移動して上書きできるため、画面全体をクリアせず一部分だけ変更できます。

時計など高頻度更新する画面では、この方式を推奨します。
